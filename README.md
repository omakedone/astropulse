## Overview
As human spaceflight expands toward long-duration Lunar bases and Mars transit missions, communication delays with Earth can reach up to 20 minutes each way. Astronauts must be able to independently evaluate their physiological and psychological health and take immediate preventive action.

**AstroPulse** acts as a real-time **"Crew Health Twin"**—an interactive visual diagnostic tool grounded in the **NASA Human Research Program (HRP)** framework that translates raw biometric telemetry into clear, actionable medical guidance.

## Key Features
- **Interactive Biometric Silhouette (SVG Body Map):** Clickable 4-zone anatomical interface (*CNS & Sleep*, *Cardiovascular*, *Musculoskeletal*, and *Metabolism*) with instant color-coded triage (**Green** = Optimal, **Yellow** = Elevated Risk, **Red** = Critical / Flight Surgeon Escalation).
- **Real-Time Telemetry & Scenario Presets:** Manual input sliders for 6 core metrics (heart rate, systolic blood pressure, blood glucose, body temperature, sleep duration, and mood score), plus instant clinical scenario presets (*Nominal*, *High Stress*, *Critical Hypoglycemia*) for rapid simulation.
- **Mission Environment Context Switcher:** Simulates environmental risk factors and communication latency across *ISS (LEO)*, *Lunar Base (Artemis)*, *Mars Transit*, and *Planetary Rover* operations.
- **7-Day Dynamic Telemetry Trends:** Interactive trend charts powered by **Chart.js** tracking physiological adaptation and fatigue across mission days.
- **Gamified EVA Readiness Score:** Daily countermeasure checklists (hydration, resistive exercise, diagnostic check-ins) that calculate readiness for Extravehicular Activity (EVA).
- **NASA HRP 5 Hazards Guide:** Built-in reference module explaining the physiological impacts of *Space Radiation*, *Isolation & Confinement*, *Distance from Earth*, *Gravity Fields*, and *Hostile/Closed Environments*.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Dark Mission-Control UI), Vanilla JavaScript (ES6+)
- **Graphics & Visualization:** Custom Interactive SVG, Chart.js (v4)
- **Hosting:** GitHub Pages (Zero-backend, offline-capable single-page architecture)
